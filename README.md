### 🔐 Secure Spread Spectrum Image Steganography System

<img src="https://img.shields.io/badge/AES--GCM-Encryption-blue?style=for-the-badge" />
<img src="https://img.shields.io/badge/FHSS-Spread%20Spectrum-purple?style=for-the-badge" />

</div>

A secure image steganography framework combining Frequency Hopping Spread Spectrum (FHSS), AES-GCM authenticated encryption, and error correction techniques.

**Key Features:**

- 🔒 AES-GCM authenticated data encryption.
- 🖼️ Secure information hiding across RGB image channels.
- 📡 Frequency Hopping Spread Spectrum techniques.
- 🔑 Secret-seed-based data distribution.
- 🛡️ Error correction for improved data recovery.
- 🔍 Improved confidentiality and resistance to basic detection techniques.
